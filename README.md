## 🛠 Troubleshooting Common Issues

If you face problems while using the tool, try these steps:

### Application Does Not Start
Check if your graphics card drivers are current. Visit the website of your graphics card manufacturer to download the latest updates.

### Slow Performance
The software uses your computer's memory to process video. Close other programs while editing to free up system resources.

### File Not Found Error
Ensure that your source video files remain in the same folder where you stored them when you imported them. The software creates a link to the original file on your storage drive. If you rename or move the source file, the software cannot see the footage.
